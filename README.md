# 6D Gauge Theory: Framework Teorico Completo 🌌

## Panoramica

Questo repository contiene il framework teorico e computazionale completo per una teoria gauge a sei dimensioni con tre coordinate temporali e tre spaziali. La teoria estende lo spaziotempo di Minkowski attraverso una struttura gauge SO(3,3) con rottura spontanea di simmetria.

## 🚀 Caratteristiche Principali

- ✅ Formalismo BRST per consistenza quantistica
- ✅ Rinormalizzabilità a un loop dimostrata  
- ✅ Unitarietà verificata numericamente
